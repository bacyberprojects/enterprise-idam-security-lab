
# Enterprise IDAM Security Lab — Practical Exercises

## Organisation

Southern Cross Financial Services (SCFS) is a fictional financial services organisation based in Melbourne, Australia.

The organisation has 50 simulated employees across five departments:

- IT
- Finance
- Human Resources
- Operations
- Customer Service

## Lab Objective

This lab demonstrates how a cybersecurity analyst can identify and manage identity and access management (IAM) risks using Python.

## Practical Exercises

1. Create a fictional employee identity dataset.
2. Implement Role-Based Access Control (RBAC) checks.
3. Detect excessive and unauthorised privileges.
4. Simulate Joiner-Mover-Leaver (JML) processes.
5. Perform automated user access reviews.
6. Generate IAM risk findings and remediation reports.

## Technologies

- Python
- CSV files
- GitHub
- Markdown

## Lab Structure

- `data/` — Fictional employee and access datasets.
- `scripts/` — Python scripts for IAM security checks.
- `reports/` — Generated security findings and evidence.

## Security Principles

- Least Privilege
- Role-Based Access Control (RBAC)
- Separation of Duties
- Identity Lifecycle Management
- Periodic Access Reviews
- Audit Logging

## Project Scope

This is a simulated cybersecurity portfolio project.

All employee identities, permissions, applications, and security findings are fictional.

No production systems or real employee accounts are accessed or modified.
